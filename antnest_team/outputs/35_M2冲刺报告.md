# 35 antNest M2 冲刺报告（数据质量 × BPE × 对话模式）

## 一、五大成果

### 1. 语料清洗（Agent 3，cleaner.py）
- 根因治理：M0 采样中的乱码（搀洀椀…）源自 .doc 提取残留的 UTF-16 十六进制噪声
- 方法：以 34 份团队交付物构建"干净字符集"，行内罕见字符占比 >15% 即剔除
- 实效：**剔除 290 行噪声 / 6,496 字符（占 6.4%）**，清洗后语料 95,177 字符
- v3 采样已**零乱码**（对照 M0/v2 采样可见）

### 2. BPE tokenizer（Agent 3+24，bpe.py，自研实现）
- 行级词频 + 迭代合并，中文友好；rank 贪心编码，接口与字符版完全对齐
- 词表 2,200（基础字符 ~1,500 + 700 合并）
- **压缩 3.56×**：94,875 字符 → 26,686 tokens（tokens/char 0.281）

### 3. v3 预训练（Agent 24/12）
- TinyGPT 4L-128d-4h，**1.39M 参数**（v2 的 2.2×），ctx 256，300 步 / 106s（CPU）
- best val 5.843/token；**跨 tokenizer 须归一化比较**：5.843 × 0.281 ≈ **1.64 nat/char**，
  对比 v2 的 3.84 nat/char——**每字符预测误差降低 2.3 倍**（Agent 2 分析方法落地）
- 采样质量实测提升："模型结构"的智能的研究，能够与模型训练，打磨细致力于使用
  真实复杂的方式。2.知名高热情；具备好奇心…"——成串通顺短语，无乱码

### 4. SFT3（Agent 25）
- 40 条指令微调 v3 基座，120 epoch / 30s，best val **2.39**
- 动作协议生成稳固（采样直接输出 ```action JSON 工具调用）

### 5. Harness 对话模式（Agent 5+7，chat.py）
- 多轮 Chat：SFT 模板拼历史 → ctx 截断 → 采样，记录至 artifacts/chat_log.md
- `AntNestLLMClient` 升级：扫描 artifacts 自动选优（SFT 优先、最新者胜），Char/BPE 词表自适应
- 实测对话（本地 sft3 模型，无任何外部 API）：
  > 用户：蚁巢团队做什么？
  > 蚁巢：…其使命围绕 antNest LLM 训练与 antNest Harness 建设展开，
  > 以工程与创新共同推进 AGI 目标…
