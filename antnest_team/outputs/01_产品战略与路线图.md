# 01 antNest 产品战略与路线图

- 负责人：AI 产品经理（Agent 17）

## 双产品线
1. **antNest LLM（蚁巢大模型）**：从团队自有语料起步的预训练模型线，本次 M0 已交付
   595K 参数 TinyGPT 参考实现并完成 300 步预训练（loss 7.34→2.44）。
2. **antNest Harness（蚁巢智能体外壳）**：Agent Loop + 工具沙箱 + 记忆 + 多智能体，
   本次 M0 已交付可运行包并通过 9/9 测试。

## 协同机制
- Harness 的 LLM 抽象层（llm.py）同时支持 OpenAI 兼容端点与离线 Mock；
  antNest LLM 训练成熟后经同一接口接入，实现"模型与 Harness 共同进化"。

## 里程碑
- M0（已完成）：LLM 训练管线跑通 + Harness 最小闭环 + 质量门禁
- M1：真实 LLM 接入 Harness，端到端任务评测集
- M2：后训练（SFT/RL）与 Agent 能力强化
- M3：多模态与 Frontier 方向接入
